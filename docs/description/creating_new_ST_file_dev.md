# Создание нового ST файла 
## Функционал со стороны пользователя 
1) Пользователь в редакторе файлов находится в той вкладке где хочет создать файл.
2) Нажимает кнопку "Создать ST-файл"
3) В появившемся окне пишит Имя нового файла 
4) Нажав кнопку "ОК" создается новый файл

## Функционал программы
1) В классе `FileEditorWindow` модуля `file_editor.py` в методе `_setup_connections()` запускается перехватчик сигнала `new_st_file`, который создан в классе `ToolbarManager` модуль `toolbar_manager.py` и включает сигнал при нажатии на кнопку *"Создать ST файл"*.
2) Метод `_handle_new_st_file()` обрабатывает перехват этого сигнала
- Открываем диалог для ввода имени нового файла
- через метод `_set_active_tab()` получаем имя активной вкладки
- полученное имя активной вкладки `active_tab_name` и имя файла что внес пользователь диалоговое окно `name` передаем параметрами в метод `create_new_st_file()` что реализован в классе `FileOperations` модуля `file_operations.py`
- метод `create_new_st_file()` создает новый  ST-файл и возвращает путь к нему
    - определяем путь к файлу: передаем параметры `"st"`, `name_file`, `tab_name` в метод  `_create_file_path()`
    - метод `_create_file_path()` Получает путь к папке закладок, проверяет его существование, а затем конструирует полный путь к файлу в подкаталоге с именем вкладки внутри папки закладок.
    - создаем шаблон нового файла `st` через метод `_get_st_base()` передаем параметр имя файла без расширения `name_file`, метод нам вернет шаблон для нового ST-файла
    - полученные данные в виде полного пути к файлу `file_path`, и шаблона содержимого файла `base_template` передаем их методу `write_file()` из класса `FileManager` модуль `file_manager.py`
    - метод `write_file()` записывает содержимое в файл по указанному пути
3) Добавляем созданный файл в модель дерева файлов через метод `add_files_to_tab()` класса `TreeModelManager`модуль `tree_model_manager.py`
   - в метод `add_files_to_tab()` передаем параметры  имя активной вкладки `active_tab_name` и полный путь к файлу упакованный в список `[file_path]` по условию метода
     - Для каждого пути в списке файлов метод пытается получить данные файла с помощью внутреннего метода _get_file_data. Если данные успешно получены и файл успешно добавлен в модель вкладки (через метод add_file), обновляется внутренняя карта связи файлов и вкладок (_file_to_tabs). Возвращает True, если хотя бы один файл был успешно добавлен.
4) Автоматически открываем новый файл в редакторе через метод `open_file_in_editor()`
    - Определяет тип редактора на основе расширения файла, создает экземпляр редактора с помощью фабрики, загружает в него файл, заменяет текущий редактор в интерфейсе и обновляет сообщение в строке состояния.

# Создание нового ST файла

## Функционал со стороны пользователя

1. Пользователь в редакторе файлов находится в той вкладке где хочет создать файл
2. Нажимает кнопку "Создать ST-файл"
3. В появившемся окне пишит Имя нового файла
4. Нажав кнопку "ОК" создается новый файл

## Функционал программы

### 1. Инициализация процесса
В классе `FileEditorWindow` модуля `file_editor.py` в методе `_setup_connections()` запускается перехватчик сигнала `new_st_file`, который создан в классе `ToolbarManager` модуль `toolbar_manager.py` и включает сигнал при нажатии на кнопку *"Создать ST файл"*.

### 2. Обработка создания файла
Метод `_handle_new_st_file()` обрабатывает перехват этого сигнала:

- **Открываем диалог** для ввода имени нового файла
- **Получаем активную вкладку** через метод `_set_active_tab()`
- **Передаем параметры** в метод `create_new_st_file()`:
  - Имя активной вкладки `active_tab_name`
  - Имя файла `name` из диалогового окна

### 3. Создание ST-файла
Метод `create_new_st_file()` создает новый ST-файл и возвращает путь к нему:

- **Определяем путь к файлу** через метод `_create_file_path()` с параметрами:
  - `"st"` - расширение файла
  - `name_file` - имя файла
  - `tab_name` - имя вкладки

- **Создаем шаблон содержимого** через метод `_get_st_base()` с параметром:
  - `name_file` - имя файла без расширения

- **Записываем файл** через метод `write_file()` класса `FileManager` с параметрами:
  - `file_path` - полный путь к файлу
  - `base_template` - шаблон содержимого файла

### 4. Интеграция с моделью данных
**Добавляем созданный файл в модель дерева файлов** через метод `add_files_to_tab()` класса `TreeModelManager` модуль `tree_model_manager.py`:

- **Передаем параметры**:
  - `active_tab_name` - имя активной вкладки
  - `[file_path]` - полный путь к файлу упакованный в список

- **Логика метода**:
  - Для каждого пути в списке файлов метод пытается получить данные файла с помощью внутреннего метода `_get_file_data`
  - Если данные успешно получены и файл успешно добавлен в модель вкладки (через метод `add_file`)
  - Обновляется внутренняя карта связи файлов и вкладок (`_file_to_tabs`)
  - Возвращает `True`, если хотя бы один файл был успешно добавлен

### 5. Автоматическое открытие
**Автоматически открываем новый файл в редакторе** через метод `open_file_in_editor()`:

- Определяет тип редактора на основе расширения файла
- Создает экземпляр редактора с помощью фабрики
- Загружает в него файл
- Заменяет текущий редактор в интерфейсе
- Обновляет сообщение в строке состояния

```sequenceDiagram

    FE->>FE: _handle_new_st_file()
    FE->>FE: _set_active_tab()

    FO->>FO: _get_st_base(name_file)
    FO->>FM: write_file(file_path, base_template)
    
    FM->>FM: Создает папки (если нужно)
    FM->>FM: Записывает файл на диск
    
    FO-->>FE: Возвращает file_path
    
    FE->>TM: add_files_to_tab(active_tab_name, [file_path])
    
    TM->>TM: _get_file_data(file_path)
    TM->>SM: add_file(file_path, data)
    TM->>TM: Обновляет _file_to_tabs
    
    FE->>FE: open_file_in_editor(file_path)
    Note over FE: Создает редактор через EditorFactory<br/>Загружает файл<br/>Заменяет текущий редактор
    
    FE-->>User: Показывает новый файл в редакторе
```
