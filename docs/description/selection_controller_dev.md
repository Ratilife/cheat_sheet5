# модуль selection_controller.py

в модуле реализован класс TreeSelectionController унаследован от класса QObject библиотеки PySide6.QtCore
Класс TreeSelectionController это контроллер для обработки выделения элементов в дереве.
Получает контект из кэш или модели.

## Основные Сигналы:
    
**content_for_sidepanel = Signal(str, str, str)**   *запрашиваемый данные  в окне с которым работает пользователь*
        - издает сигнал в методе **_process_content()** при работе с деревом в классе **SidePanel**
        - принимает сигнал метод on_display_content в классе  **SidePanel**
        - подключен сигнал в методе _connect_selection_signals() в классе  **SidePanel** и запускается при инициализации
            экземпляра класса
        параметры:
                **content_type**   тип элемента: 'template', 'folder', 'file', 'markdown'
                **content**        Содержимое файла, привязано к типу контента, выводитсяв редактор 
                **path_file**      путь к файлу. Это ключ к кэш 
    
**content_for_editor = Signal(str, str, str)** *запрашиваемый данные  в окне с которым работает пользователь*
        - издает сигнал в методе **_process_content()** при работе с деревом в классе **FileEditorWindow**
        - принимает сигнал метод on_display_content() в классе  **FileEditorWindow** 
        - подключен сигнал в методе _connect_selection_signals() вклассе  **FileEditorWindow** и запускается при инициализации
            экземпляра класса        
        параметры:
                **content_type**   тип элемента: 'template', 'folder', 'file', 'markdown'
                **content**        Содержимое файла, привязано к типу контента, выводитсяв редактор 
                **path_file**      путь к файлу. Это ключ к кэш 

**selection_changed = Signal(dict)**   выбранный параметр изменен (Сигнал о изменении выделения)
        - издает сигнал в методе _handle_selection()  в классе **TreeSelectionController**
        - принимает сигнал метод selection_changed() в классе **FileEditorWindow**
        -подключен сигнал к методу _connect_selection_signals() класс **FileEditorWindow**
        - принимает сигнал  метод on_update_selection_status() класса **SidePanel**
        - подключен сигнал к методу _connect_selection_signals класса **SidePanel**
        параметры:
             metadata: {type, name, path, has_content}
**error_occurred = Signal(str)**  # error_message       произошла ошибка
        - издает сигнал в методах:  connect_tree_view(), _handle_selection(), _process_content() класс **TreeSelectionController**    
        - принимает сигнал метод on_show_selection_error()  в классе **SidePanel**
        -подключен сигнал в методе _connect_selection_signals() в классе  **SidePanel** и запускается при инициализации
            экземпляра класса
**content_for_element = Signal(str, str, str, dict)**  # type, element_content, path, element_info
        *Еще не описан*

## Конструктор:
**Сигнатура:** `__init__(content_cache, parent=None)`
### **Параметры:**
    *   `content_cache`: **Обязательный.** Объект, предоставляющий доступ к кэшированному содержимому файлов. Ожидается, что он реализует метод `get(path)`.
    *   `parent` (`QObject`, опционально): Родительский объект в иерархии Qt.

*Важность: Без корректного объекта кэша функциональность извлечения контента будет ограничена только данными, непосредственно хранящимися в элементах дерева.*

### *Инициализация атрибутов*:
`super().__init__(parent)` - родительский конструктор
`self.content_cache` - Прямое сохранение переданного параметра `content_cache`
    - Назначение: Делает кэш контента доступным для всех методов класса
    - Использование: используется в методе _extract_content() для резервного получения контента

`self.current_source` - отслеживает активный источник (дерево), к которому подключен контроллер в данный момент
    `это переменная-идентификатор, которая отслеживает, к какому именно дереву (источнику выборки) подключен контроллер в данный момент. Она решает фундаментальную проблему маршрутизации: "Куда отправить контент, если контроллер может работать с несколькими деревьями?"`
    - Тип: строка `str`
    - Начальное значение: Пустая строка ''
    - Жизненный цикл:
        • Инициализация пустой строки 
        • Устанавливается в `connect_tree_view()` при подключении к дереву
        • Используется в `_process_content()` для определения направления маршрутизации контента
    *Важность: Критически важен для корректной работы системы маршрутизации контента*
    **Практические задачи** (*примеры возможного использования*):
        - Маршрутизация контента к разным получателям
          ` есть два дерева — одно в боковой панели, другое в редакторе. При клике на элемент нужно отправлять контент в разные места`
```python
# Подключаем контроллер к разным деревьям
controller.connect_tree_view(sidepanel_tree, 'sidepanel')
                controller.connect_tree_view(editor_tree, 'editor')
                # Внутри _process_content:
                if self.current_source == 'sidepanel':
                # Отправляем в боковую панель для предпросмотра
                self.content_for_sidepanel.emit(...)
                elif self.current_source == 'editor':
                # Отправляем в редактор для редактирования
                self.content_for_editor.emit(...)
```     
        - Разное поведение для разных источников
          `Для боковой панели нужен только предпросмотр, а для редактора — полный контент с возможностью редактирования.`
```python
def _process_content(self, metadata, item, source_name):
    content = self._extract_content(metadata, item)
    
    if source_name == 'sidepanel':
        # Для боковой панели - ограниченный предпросмотр
        preview = content[:500] + "..." if len(content) > 500 else content
        self.content_for_sidepanel.emit(metadata['type'], preview, metadata.get('path', ''))
    
    elif source_name == 'editor':
        # Для редактора - полный контент
        self.content_for_editor.emit(metadata['type'], content, metadata.get('path', ''))
```
        - Разная логика обработки ошибок
          `В редакторе ошибки должны быть более детальными, в боковой панели — краткими.` 
```python
def _handle_selection(self, index):
    try:
        # основная логика...
    except Exception as e:
        if self.current_source == 'editor':
            self.error_occurred.emit(f"Ошибка редактора: {str(e)}")
        else:
            self.error_occurred.emit("Не удалось загрузить контент")
```

          ` Нужно логировать, из какого источника пришел запрос для аналитики`

          `Если контроллер обрабатывает запросы от нескольких источников, можно реализовать приоритеты.`

## Методы:

`connect_tree_view(tree_view, source_name)`
    Подключает контроллер к сигналу `clicked` древовидного представления.
     **Параметры:**
        `tree_view`: **Обязательный.** Объект древовидного представления (например, `QTreeView`), который имеет сигнал `clicked`(унаследованный от QAbstractItemView).
        `source_name` (`str`): **Обязательный.** Уникальный идентификатор источника, который определяет, куда будет направлен контент (например, `'sidepanel'` или `'editor'`).
            *Важность: Это значение сохраняется в self.current_source и используется throughout всем жизненным циклом обработки выделения*
    **Исключения:**
        Не выбрасывает явных исключений, но в случае ошибки излучает сигнал `error_occurred`, если переданный `tree_view` не поддерживает сигнал `clicked`.
    **Назначение и роль в архитектуре**
        1. Метод служит точкой входа для интеграции контроллера с пользовательским интерфейсом. Он решает следующие ключевые задачи:
        2. Установка соединения между сигналом клика дерева и слотом обработки контроллера
        3. Идентификация источника выборки для корректной маршрутизации контента
        4. Валидация совместимости переданного дерева с ожидаемым интерфейсом
        5. Активация контекста выполнения для последующих операций
