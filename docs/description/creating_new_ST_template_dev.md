# Создание нового Шаблона

## Функционал программы

### 1. Инициализация процесса
В классе `FileEditorWindow` модуля `file_editor.py` в методе `_setup_connections()` запускается перехватчик сигнала `new_template`, который создан в классе `ToolbarManager` модуль `toolbar_manager.py` и включает сигнал при нажатии на кнопку *"Создать Шаблон"*.

### 2. Обработка создания шаблона
Метод `_handle_new_template()` обрабатывает перехват этого сигнала:

- **Открываем диалог** для ввода имени нового шаблона
- Через метод `new_template()` класса `TreeModelManager` модуль `tree_model_manager.py` создает новый шаблон на основе выбранного элемента, запуская метод `creating_an_element()`

### 3. Создание элемента шаблона
Метод `creating_an_element()` класса `TreeModelManager` модуль `tree_model_manager.py` принимает параметры:

- `name_template` - имя шаблона
- `'template'` - тип элемента модели дерева

**Логика метода:**

- **Определяет контекст создания** - где именно нужно создать новый элемент, в зависимости от типа выбранного в данный момент элемента (папка, файл, шаблон)
- **Проверяет наличие вкладки** `_tab_widget`
- **Получает информацию о выбранном элементе** через метод `get_selection_info()` - информацию о текущем выделенном элементе в активной вкладке
