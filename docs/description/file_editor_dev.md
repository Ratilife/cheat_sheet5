# Модуль `file_editor.py`

## Назначение
Реализует главное окно редактора файлов с поддержкой вкладок, древовидной структурой файлов и различными типами редакторов (ST, Markdown).

## Ключевые возможности
- Отображение файловой структуры проекта в виде вкладок и деревьев.
- Открытие и редактирование файлов в специализированных редакторах (`.st`, `.md`).
- Создание новых файлов и папок.
- Сохранение изменений.
- Синхронизация выделения между деревом файлов и редактором.

## Архитектурная роль
Является **View-компонентом** в архитектуре приложения. Оно отображает данные из моделей (`tree_model_manager`) и реагирует на пользовательский ввод, делегируя бизнес-логику контроллерам и менеджерам.

## Зависимости
- `PySide6.QtWidgets`, `PySide6.QtCore` - для UI.
- `pathlib.Path` - для работы с путями.
- `editor.base_editor`, `editor.editor_factory` - для управления редакторами.
- `operation.file_operations` - для операций с файловой системой.

---
## Класс `FileEditorWindow`

Главное окно приложения. Наследуется от `QMainWindow`.

### Назначение
Центральный координатор UI. Управляет layout'ом (сплиттер, вкладки, панели), текущим активным редактором, обрабатывает пользовательские действия (сохранить, создать файл) и синхронизирует состояние с другими компонентами (например, с боковой панелью).
