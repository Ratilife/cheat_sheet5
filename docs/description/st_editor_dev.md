# Модуль st_editor.py
## Назначение
Редактор для файлов с расширением `.st` с поддержкой отслеживания внешних изменений и разрешения конфликтов. 
Предоставляет функциональность текстового редактора с системой наблюдения за файлами.

## Архитектура
Наследуется от `BaseFileEditor`, использует паттерн Наблюдатель через `FileWatcher` для мониторинга изменений файловой системы.

## Зависимости
### Внешние пакеты
- **PySide6.QtWidgets** - базовые виджеты (QWidget, QVBoxLayout, QTextEdit)
- **PySide6.QtCore** - система сигналов, таймеры (Signal, QTimer)
- **pathlib.Path** - объектно-ориентированная работа с путями файлов
- **typing** - аннотации типов (Optional)

### Внутренние модули
- **`observers.file_watcher.FileWatcher`** - ядро системы отслеживания изменений файлов
- **`src.editor.base_editor.BaseFileEditor`** - абстрактный базовый класс, определяющий API редактора
- **`src.widgets.st.st_highlighter.STHighlighter`** - планируемый компонент для подсветки синтаксиса

### Архитектурные зависимости
- **Наследование от `BaseFileEditor`**:
  - Получает базовую реализацию управления файлами
    - Реализует абстрактные методы `load()`, `save()`,`save_as()`, `get_editor_widget()`,`can_undo()`,`can_redo()`,
    `undo()`,`redo()`, `set_content()`,  `get_content()`
- **Композиция с `FileWatcher`**:
  - Делегирует отслеживание файловой системы
  - Обрабатывает сигналы об изменениях
- **Сигнальная система Qt**:
  - `external_update_detected` - для уведомления о внешних изменениях
  - `file_conflict_detected` - для разрешения конфликтов редактирования

#### FileWatcher
- **Назначение**: Мониторинг изменений в файловой системе в реальном времени
- **Использование**: 
  - Отслеживание текущего редактируемого файла
  - Мониторинг родительской директории для обнаружения перемещений/удалений
- **Особенности**: Использует дебаунсинг для группировки множественных изменений


### Циклические зависимости
Отсутствуют - модуль зависит только от модулей более низкого уровня.

## Основные компоненты

### Класс STEditor

#### Сигналы:
- `external_update_detected(str)` - обнаружено внешнее изменение файла
- `file_conflict_detected(str, str)` - конфликт между локальными и внешними изменениями
- `file_became_readonly(str)` - файл стал доступен только для чтения
- `watching_status_changed(bool)` - изменение статуса отслеживания

#### Сигналы объявлены в родительском классе
- `undo_available(bool)` 
- `redo_available(bool)`
 
- `modification_changed(bool)` - Сигнал об изменении модифицированного состояния (is_modified)
- `file_saved_as(Path)` - Сигнал о том, что файл успешно сохранен по новому пути
- `error_occurred(str, str)` - Сигнал о возникновении ошибки (сообщение, уровень)

#### Подробнее о сигналах

***external_update_detected(str)***
*Назначение:* **Уведомление о том, что редактируемый файл был изменен внешней программой и автоматически обновлен в редакторе.**

*Когда испускается:*
- Файл изменен внешней программой (обнаружено через FileWatcher)
- Редактор не содержит несохраненных изменений (is_modified == False)
- Содержимое файла на диске отличается от текущего содержимого редактора
- Файл существует и доступен для чтения
⚠️ НЕ испускается при конфликте изменений (для этого есть file_conflict_detected)

*Параметры:*
-  **message (str):** Сообщение для пользователя о характере изменения.
-  **Всегда содержит строку:** *"Файл обновлен внешней программой"*

*Обработчики должны:*
-  Показать уведомление пользователю о внешнем изменении
-  Обновить статусную строку или индикаторы UI
-  НЕ модифицировать содержимое редактора (оно уже обновлено автоматически)

*Место испускания сигнала(emit)*
- метод _process_external_update() класс **STEditor** модуль `st_editor.py`
- метод _process_external_update() класс **MarkdownEditor** модуль `markdown_editor.py`  

*Место подключения сигнала(connect)*
  *Важно подключение в сигналу external_update_detected в проекте не описано*

***file_conflict_detected(str, str)***
*Назначение:* **Обнаружен конфликт между локальными и внешними изменениями**

*Когда испускается:*
- Файл изменен внешней программой И редактор содержит несохраненные изменения
- Содержимое редактора отличается от содержимого на диске
- Пользователь должен принять решение о разрешении конфликта

*Параметры:*
- **local_content (str)**: Текущее содержимое редактора (локальные изменения)
- **external_content (str)**: Содержимое файла на диске (внешние изменения)

*Обработчики должны:*
- Показать диалог выбора версии (сохранить локальную, принять внешнюю, объединить)
- Вызвать соответствующий метод редактора на основе выбора пользователя
- Предупредить о возможной потере данных

*Место испускания сигнала(emit)*
- метод _process_external_update() класс **STEditor** модуль `st_editor.py`
- метод _process_external_update() класс **MarkdownEditor** модуль `markdown_editor.py`  

*Место подключения сигнала(connect)*
  *Важно подключение в сигналу external_update_detected в проекте не описано*

***file_became_readonly(str)***
*Назначение:* **Файл стал доступен только для чтения**

*Когда испускается:*
- Файл был удален внешней программой
- Права доступа к файлу изменились
- Файл перемещен или переименован

*Параметры:*
- **file_path (str)**: Путь к файлу, который стал read-only

*Обработчики должны:*
- Перевести редактор в режим только для чтения
- Показать предупреждение пользователю
- Предложить сохранить копию под другим именем

*Место испускания сигнала(emit)*
- метод _on_external_file_deleted() класс **STEditor** модуль `st_editor.py`
- метод _on_external_file_deleted() класс **MarkdownEditor** модуль `markdown_editor.py`

*Место подключения сигнала(connect)*
  *Важно подключение в сигналу external_update_detected в проекте не описано*

***watching_status_changed(bool)***
*Назначение*: **Изменение статуса отслеживания файла**

*Когда испускается:*
- При запуске отслеживания нового файла
- При остановке отслеживания
- При смене файла через `save_as()`

*Параметры:*
- **enabled (bool):** `True` - отслеживание активно, `False` - приостановлено

*Обработчики должны:*
- Обновить индикатор статуса отслеживания в UI
- Включить/выключить соответствующие элементы управления

***undo_available(bool)***

*Назначение*: **Уведомляет о изменении доступности операции "Отменить" (Undo).**

*Когда испускается*:
- После любого изменения содержимого редактора
- После выполнения операции отмены/повтора
- После загрузки нового файла
- После сохранения файла (очистка истории)

*Параметры*:
- `available` (bool): `True` - операция "Отменить" доступна, `False` - недоступна

*Обработчики должны*:
- Активировать/деактивировать кнопку "Отменить" в UI
- Обновить состояние соответствующего пункта меню
- Возможно обновить tooltip или статус

*Место испускания сигнала(emit)*
- метод save_state() класс BaseFileEditor модуль `base_editor.py`
- метод after_save_cleanup() класс BaseFileEditor модуль `base_editor.py`
- метод undo() класс  **MarkdownEditor** модуль `markdown_editor.py`
- метод undo() класс **STEditor** модуль `st_editor.py`
- метод redo() класс  **MarkdownEditor** модуль `markdown_editor.py`
- метод redo() класс **STEditor** модуль `st_editor.py`
- метод set_content() класс **MarkdownEditor** модуль `markdown_editor.py`
- метод set_content() класс **STEditor** модуль `st_editor.py`

*Место подключения сигнала(connect)*
- метод _set_current_editor() класс **STEditor** модуль `st_editor.py`

*Место отключения сигнала(disconnect)*
- метод _set_current_editor() класс **FileEditorWindow** модуль `file_editor.py`

***redo_available(bool)***

*Назначение*: **Уведомляет о изменении доступности операции "Повторить" (Redo).**

*Когда испускается*:
- После операции отмены (становится доступным)
- После выполнения повтора (становится недоступным)
- После нового редактирования (очищает стек повтора)
- После загрузки/сохранения файла

**Параметры**:
- **available (bool)**: `True` - операция "Повторить" доступна, `False` - недоступна

*Обработчики должны*:
- Активировать/деактивировать кнопку "Повторить"
- Обновить пункт меню "Повторить"
