# Модуль st_editor.py
## Назначение
Редактор для файлов с расширением `.st` с поддержкой отслеживания внешних изменений и разрешения конфликтов. 
Предоставляет функциональность текстового редактора с системой наблюдения за файлами.

## Архитектура
Наследуется от `BaseFileEditor`, использует паттерн Наблюдатель через `FileWatcher` для мониторинга изменений файловой системы.

## Зависимости
### Внешние пакеты
- **PySide6.QtWidgets** - базовые виджеты (QWidget, QVBoxLayout, QTextEdit)
- **PySide6.QtCore** - система сигналов, таймеры (Signal, QTimer)
- **pathlib.Path** - объектно-ориентированная работа с путями файлов
- **typing** - аннотации типов (Optional)

### Внутренние модули
- **`observers.file_watcher.FileWatcher`** - ядро системы отслеживания изменений файлов
- **`src.editor.base_editor.BaseFileEditor`** - абстрактный базовый класс, определяющий API редактора
- **`src.widgets.st.st_highlighter.STHighlighter`** - планируемый компонент для подсветки синтаксиса

### Архитектурные зависимости
- **Наследование от `BaseFileEditor`**:
  - Получает базовую реализацию управления файлами
    - Реализует абстрактные методы `load()`, `save()`,`save_as()`, `get_editor_widget()`,`can_undo()`,`can_redo()`,
    `undo()`,`redo()`, `set_content()`,  `get_content()`
- **Композиция с `FileWatcher`**:
  - Делегирует отслеживание файловой системы
  - Обрабатывает сигналы об изменениях
- **Сигнальная система Qt**:
  - `external_update_detected` - для уведомления о внешних изменениях
  - `file_conflict_detected` - для разрешения конфликтов редактирования

#### FileWatcher
- **Назначение**: Мониторинг изменений в файловой системе в реальном времени
- **Использование**: 
  - Отслеживание текущего редактируемого файла
  - Мониторинг родительской директории для обнаружения перемещений/удалений
- **Особенности**: Использует дебаунсинг для группировки множественных изменений


### Циклические зависимости
Отсутствуют - модуль зависит только от модулей более низкого уровня.

#### Подробнее о сигналах

***external_update_detected(str)***
*Назначение:* **Уведомление о том, что редактируемый файл был изменен внешней программой и автоматически обновлен в редакторе.**

*Когда испускается:*
- Файл изменен внешней программой (обнаружено через FileWatcher)
- Редактор не содержит несохраненных изменений (is_modified == False)
- Содержимое файла на диске отличается от текущего содержимого редактора
- Файл существует и доступен для чтения
⚠️ НЕ испускается при конфликте изменений (для этого есть file_conflict_detected)

*Параметры:*
-  **message (str):** Сообщение для пользователя о характере изменения.
-  **Всегда содержит строку:** *"Файл обновлен внешней программой"*

*Обработчики должны:*
-  Показать уведомление пользователю о внешнем изменении
-  Обновить статусную строку или индикаторы UI
-  НЕ модифицировать содержимое редактора (оно уже обновлено автоматически)

*Место испускания сигнала(emit)*
- метод _process_external_update() класс **STEditor** модуль `st_editor.py`
- метод _process_external_update() класс **MarkdownEditor** модуль `markdown_editor.py`  

*Место подключения сигнала(connect)*
  *Важно подключение в сигналу external_update_detected в проекте не описано*

***file_conflict_detected(str, str)***
*Назначение:* **Обнаружен конфликт между локальными и внешними изменениями**

*Когда испускается:*
- Файл изменен внешней программой И редактор содержит несохраненные изменения
- Содержимое редактора отличается от содержимого на диске
- Пользователь должен принять решение о разрешении конфликта

*Параметры:*
- **local_content (str)**: Текущее содержимое редактора (локальные изменения)
- **external_content (str)**: Содержимое файла на диске (внешние изменения)

*Обработчики должны:*
- Показать диалог выбора версии (сохранить локальную, принять внешнюю, объединить)
- Вызвать соответствующий метод редактора на основе выбора пользователя
- Предупредить о возможной потере данных

*Место испускания сигнала(emit)*
- метод _process_external_update() класс **STEditor** модуль `st_editor.py`
- метод _process_external_update() класс **MarkdownEditor** модуль `markdown_editor.py`  

*Место подключения сигнала(connect)*
  *Важно подключение в сигналу external_update_detected в проекте не описано*

### `_update_watching_state(enabled: bool) -> None`
*Назначение*: Обновляет внутреннее состояние отслеживания файла и уведомляет систему о изменении статуса мониторинга.

**Когда вызывается**:
- При инициализации редактора в конструкторе (`_update_watching_state(False)`)
- При загрузке файла через `load()` метод
- При изменении статуса отслеживания вручную (если будет реализован такой функционал)
- При остановке отслеживания (например, при закрытии файла)

*Параметры*:
- `enabled` (bool): Новое состояние отслеживания

- Влияет на поведение методов `_start_watching_file()` и `_stop_watching_file()`

***`set_file_watcher(file_watcher: FileWatcher) -> None***
**Назначение**: Устанавливает кастомный экземпляр FileWatcher для отслеживания изменений файлов в файловой системе.

**Когда вызывается**:
- При создании редактора с предварительно настроенным FileWatcher
- При динамической смене системы отслеживания во время работы приложения
- В тестах для подмены реального FileWatcher на mock-объект
- При необходимости использования общего FileWatcher для нескольких редакторов

**Параметры**:
- `file_watcher` (FileWatcher): Экземпляр FileWatcher для отслеживания изменений файлов
  - Должен быть валидным объектом FileWatcher
  - Не может быть `None` (используется `file_watcher or FileWatcher()` в конструкторе для дефолтного значения)

**Возвращаемое значение**: `None`

**Побочные эффекты**:
- Заменяет текущий FileWatcher на новый
- Переподключает все сигналы к новому FileWatcher
- При наличии открытого файла перезапускает его отслеживание
- Освобождает ресурсы предыдущего FileWatcher (если был установлен)

**Описание работы**:

#### Основная логика метода:
```python
def set_file_watcher(self, file_watcher: FileWatcher) -> None:
    # 1. Отключаем старый FileWatcher если он был
    if self._file_watcher:
        self._disconnect_file_watcher()
    
    # 2. Устанавливаем новый FileWatcher
    self._file_watcher = file_watcher
    
    # 3. Подключаем сигналы нового FileWatcher
    self._connect_file_watcher()
    
    # 4. Перезапускаем отслеживание текущего файла если нужно
    if self.file_path and self._watching_enabled:
        self._start_watching_file()
```

***_process_external_update(file_path: str) -> None***
**Назначение**: Обрабатывает внешние изменения файла после дебаунсинга, определяя стратегию реакции редактора.

**Когда вызывается**:
- Автоматически при получении сигнала `debounced_file_updated` от FileWatcher
- После группировки быстрых последовательных изменений (дебаунсинг)
- При обнаружении модификации файла внешней программой

**Параметры**:
- `file_path` (str): Путь к измененному файлу в строковом формате

**Возвращаемое значение**: `None`

**Побочные эффекты**:
- Читает содержимое файла с диска
- Сравнивает внешнее и локальное содержимое
- Автоматически обновляет редактор или сообщает о конфликте
- Испускает сигналы `external_update_detected` или `file_conflict_detected`
- Может изменять содержимое редактора

**Описание работы**:

#### Полная реализация метода:
```python
def _process_external_update(self, file_path: str) -> None:
    if Path(file_path) != self.file_path:
        return  # Не наш файл

    try:
        # Читаем внешнее содержимое
        with open(file_path, 'r', encoding='utf-8') as f:
            external_content = f.read()

        # Сравниваем с текущими данными редактора
        current_content = self.get_content()

        if current_content == external_content:
            return  # Содержимое одинаковое - ложное срабатывание

        elif not self.is_modified:
            # Мы не редактировали - автоматически обновляем
            self.set_content(external_content)
            self.external_update_detected.emit("Файл обновлен внешней программой")

        else:
            # КОНФЛИКТ: мы редактируем и файл изменен извне
            self.file_conflict_detected.emit(current_content, external_content)

    except Exception as e:
        self.error_occurred.emit(f"Ошибка обработки внешнего изменения: {e}", "warning")
```

        content = self.get_content()

        with open(self.file_path, 'w', encoding='utf-8') as f:
            f.write(content)

        self.is_modified = False

        # ⭐ ВЫЗЫВАЕМ ОЧИСТКУ СОСТОЯНИЯ ОТМЕНЫ
        self.after_save_cleanup()  #TODO 11.10.2025 тут проблема

        return True

    except Exception as e:
        self.error_occurred.emit(f"Ошибка сохранения файла: {e}", "error")
        return False

### `save_as(new_file_path: Path = None) -> bool`
**Назначение**: Сохраняет содержимое редактора в новый файл с полным переключением системы отслеживания и обновлением состояния редактора.

**Когда вызывается**:
- При нажатии кнопки "Сохранить как..." в UI
- При использовании горячих клавиш (Ctrl+Shift+S)
- При первом сохранении нового документа
- При необходимости сохранить копию файла под другим именем

**Параметры**:
- `new_file_path` (Path, optional): Новый путь для сохранения файла. Если `None`, должен запрашивать у пользователя.

**Возвращаемое значение**:
- `bool`: `True` - если сохранение выполнено успешно, `False` - если произошла ошибка или пользователь отменил операцию

**Побочные эффекты**:
- Создает новый файл на диске
- Останавливает отслеживание старого файла
- Начинает отслеживание нового файла
- Обновляет внутренний путь `file_path` редактора
- Сбрасывает флаг модификации `is_modified`
- Испускает сигнал `file_saved_as` с новым путем

**Описание работы**:

#### Полная реализация в STEditor:
```python
def save_as(self, new_file_path: Path = None) -> bool:
    """
    Сохраняет содержимое редактора в новый файл.

    Args:
        new_file_path: Новый путь для сохранения

    Returns:
        bool: True если сохранение прошло успешно, False в противном случае
    """
    # TODO: В реальной реализации нужно запрашивать путь у пользователя
    if new_file_path is None:
        # Временная заглушка - сохраняем в тот же путь с суффиксом
        if self.file_path:
            new_file_path = self.file_path.with_suffix('.copy.st')
        else:
            self.error_occurred.emit("Не указан путь для сохранения", "error")
            return False

    try:
        # Прекращаем отслеживание старого файла
        if self.file_path:
            self._stop_watching_file()

        # Получаем содержимое из редактора
        content = self.get_content()

        # Сохраняем в новый файл
        with open(new_file_path, 'w', encoding='utf-8') as f:
            f.write(content)

        # Обновляем путь и начинаем отслеживание нового файла
        self._file_path = new_file_path
        self._start_watching_file()

        # Сбрасываем флаг модификации
        self.is_modified = False

        # Испускаем сигнал о сохранении под новым именем
        self.file_saved_as.emit(new_file_path)

        return True

    except Exception as e:
        self.error_occurred.emit(f"Ошибка сохранения файла: {e}", "error")
        return False        
```

### `set_content(content: str) -> None`
**Назначение**: Устанавливает содержимое редактора из строки, полностью сбрасывая состояние истории изменений и инициализируя систему редактора.

**Когда вызывается**:
- При загрузке файла через `load()`
- При обработке внешних изменений файла через `_process_external_update()`
- При откате к предыдущему состоянию через `undo()/redo()`
- Программной установке содержимого из внешних источников

**Параметры**:
- `content` (str): Содержимое для отображения в редакторе

**Возвращаемое значение**: `None`

**Побочные эффекты**:
- Заменяет текущее содержимое текстового редактора
- Полностью очищает стеки отмены и повтора
- Сбрасывает флаг модификации документа
- Определяет язык программирования для подсветки синтаксиса
- Не вызывает сигнал `textChanged` (программное изменение)

**Описание работы**:

#### Полная реализация в STEditor:
```python
def set_content(self, content: str) -> None:
    """Устанавливает содержимое редактора из строки."""
    self._text_edit.setPlainText(content)

    # ⭐ ОБНОВЛЯЕМ СОСТОЯНИЕ ОТМЕНЫ
    self._undo_stack.clear()
    self._redo_stack.clear()
    self._current_state = content
    self.undo_available.emit(False)
    self.redo_available.emit(False)

    # Сбрасываем флаг модификации при установке нового содержимого
    self.is_modified = False
    # Определяем язык для подсветки по первой строке
    self._identify_language(content)
```

### `load(file_path: Path) -> bool`
**Назначение**: Загружает содержимое файла в редактор, инициализируя все связанные системы (отслеживание, состояние, определение языка).

**Когда вызывается**:
- При открытии файла через меню "Файл → Открыть"
- При переключении между файлами в multi-document интерфейсе
- При открытии файла из проводника или командной строки
- При восстановлении сессии или недавних файлов

**Параметры**:
- `file_path` (Path): Путь к файлу для загрузки

**Возвращаемое значение**:
- `bool`: `True` - если загрузка прошла успешно, `False` - если произошла ошибка

**Побочные эффекты**:
- Читает содержимое файла с диска
- Устанавливает содержимое в редактор через `set_content()`
- Обновляет внутренний путь `file_path` редактора
- Активирует систему отслеживания файла
- Определяет язык программирования для подсветки синтаксиса
- Может испускать сигналы ошибок

**Описание работы**:

#### Полная реализация в STEditor:
```python
def load(self, file_path: Path) -> bool:
    """
    Загружает содержимое файла в редактор.
    Реализация абстрактного метода BaseFileEditor.

    Args:
        file_path: Путь к файлу для загрузки

    Returns:
        bool: True если загрузка прошла успешно
    """
    try:
        with open(file_path, 'r', encoding='utf-8') as f:
            content = f.read()

        self._file_path = file_path
        self.set_content(content)

        # Начинаем отслеживание файла
        self._update_watching_state(True)
        self._start_watching_file()

        return True

    except Exception as e:
        self.error_occurred.emit(f"Ошибка загрузки файла: {e}", "error")
        return False
```
