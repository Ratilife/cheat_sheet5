## Структура пункта 2.2

### 2.2.1. Общее описание программного средства
- Назначение: кроссплатформенное средство для организации и управления учебными материалами и фрагментами кода для IT-специалистов
- Основные функции: стартовая панель, редактор файлов, система управления файлами, парсинг и подсветка синтаксиса
- Целевая аудитория: IT-студенты и начинающие разработчики

### 2.2.2. Архитектура приложения
- Архитектурный стиль: модульная архитектура с разделением на слои
- Основные слои:
  - Presentation Layer (UI) — `src/ui/`, `src/start_panel/views/`
  - Business Logic Layer — `src/managers/`, `src/controllers/`, `src/editor/`
  - Data Access Layer — `src/models/`, `src/parsers/`
  - Infrastructure Layer — `src/utils/`, `src/observers/`
- Используемые паттерны:
  - MVVM (стартовая панель)
  - Factory (создание редакторов)
  - Observer (отслеживание изменений файлов)
  - Strategy (разные типы редакторов)

### 2.2.3. UML-диаграммы
- Диаграмма компонентов: основные модули и их взаимодействие
- Диаграмма классов: ключевые классы (`EditorManager`, `FileParserService`, `STMDFileTreeModel`, `ButtonViewModel`)
- Диаграмма последовательности: сценарии (открытие файла, парсинг, создание кнопки)
- Диаграмма развертывания: компоненты и их размещение

### 2.2.4. Структура данных и хранение
- Формат хранения: файловая система + JSON-файлы (БД не используется)
- Структура данных:
  - `for_program/buttons.json` — конфигурация кнопок
  - `for_program/saved_files.json` — реестр внешних файлов
  - `bookmarks/` — рабочие файлы пользователя (ST/MD)
  - `root_folder_path.json` (в домашней директории) — конфигурация корневой папки
- Модели данных:
  - `STMDFileTreeItem` — элемент дерева файлов
  - `STMDFileTreeModel` — модель для отображения в Qt
  - `ButtonListModel` — модель для стартовой панели

### 2.2.5. Структура модулей приложения
- `src/ANTLR4/` — грамматики для парсинга (ST, MD, Python, Java, C#, 1C)
- `src/parsers/` — парсеры файлов и система кэширования
- `src/editor/` — система редакторов (ST, Markdown, Plain Text)
- `src/managers/` — менеджеры (файлов, UI, дерева, вкладок)
- `src/models/` — модели данных
- `src/ui/` — пользовательский интерфейс
- `src/start_panel/` — стартовая панель (MVVM)

### 2.2.6. Технологический стек
- Язык: Python 3
- GUI: PySide6 (Qt6)
- Парсинг: ANTLR4
- Подсветка синтаксиса: Pygments
- Тестирование: Pytest
- Хранение: JSON, файловая система

### 2.2.7. Взаимодействие компонентов
- Поток данных: UI → Managers → Parsers → Cache → Models
- Система кэширования: `ContentCache` и `MetadataCache` для оптимизации
- Фоновый парсинг: `BackgroundParser` для асинхронной обработки
